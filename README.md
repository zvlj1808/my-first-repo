# My First Repo

初めてのGitHubリポジトリへようこそ！

## このリポジトリについて

このリポジトリは、GitとGitHubの基本的なワークフロー（コミット、ブランチ、プルリクエスト）を学ぶために作成されました。

## 使い方

```bash
# リポジトリをクローン
git clone https://github.com/zvlj1808/my-first-repo.git

# ブランチを作成して作業
git checkout -b feature/my-feature

# 変更をコミット
git add .
git commit -m "Add my feature"

# プルリクエストを作成
git push origin feature/my-feature
```
